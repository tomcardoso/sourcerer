Encryption

      
Useless to anyone without your password.

      
Everything lives in one vault on your computer: the database, its salt file and any screenshots. Every page of the database is encrypted. The key that unlocks it is worked out from your password each time you open the app, and is never written down anywhere.

      
That also means there is no reset link. Forget the password and the data is gone, by design.

      
How Sourcerer protects your data, and what it doesn't →

Redaction mode

      
Working in public? Blur it.

      
One shortcut blurs every name, organization, email, phone number, handle, link and note on screen, so you can work in a café or share your screen without showing who you talk to. The same shortcut brings it all back.

Shared projects

      
Work a story together, with no server in the middle.

      
A shared project is a second encrypted database in a folder your team already syncs: Dropbox, OneDrive, Google Drive or a network drive. Each Sourcerer reads and writes it every two minutes. The sync service only ever holds an encrypted file.

      
Cloud folders copy whole files and never merge them, so two people saving at the same moment can leave a “conflicted copy”. Work a few minutes apart. What sync does and doesn't promise

Questions

      
Before you start.

      
Anything else is in the user guide, or ask on GitHub.

    

    

      

        What does it cost?
        
Nothing. Sourcerer is free and open source, with no paid tier and no subscription. If it helps your work, you can sponsor its development.

      

      

        Can I get my data back if I forget my password?
        
No. There is no reset, recovery code or back door, because any of those would also be a way in for someone else. Use a passphrase you'll remember, and keep a backup. Your master password

      

      

        Does it send my contacts anywhere?
        
No. Your data stays in the vault on your computer, or in a shared folder you choose for a shared project. The app connects to the internet only to fetch news-alert feeds you've added, to send a website to the Wayback Machine if you turn that on, and to check GitHub for a new version. Network traffic

      

      

        Can I use it on more than one computer?
        
Your vault can live in a folder you carry or sync, such as an external drive or Dropbox, but open it on only one computer at a time. To work alongside colleagues, use a shared project instead. Vault location

      

      

        Can I bring my existing contacts?
        
Yes. Import a CSV file, or a vCard file exported from Apple Contacts, Google Contacts or any other address book. Import and export

      

      

        Is it a secure messaging tool?
        
No. Sourcerer keeps records of your sources safe on your computer. It doesn't send messages or hide your communications; use a tool built for that, such as Signal. What Sourcerer is not
